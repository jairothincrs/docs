## Una API, múltiples servicios

Todos los servicios de SmartApe son accesibles mediante **una única API centralizada**. Esto significa que con una sola integración puedes acceder a RAG, OCR, procesamiento de video y todos los demás servicios disponibles.

## Endpoint base

Todas las peticiones a servicios de SmartApe se realizan a través del siguiente endpoint:

```bash
POST https://dfofxhxkdkwelswhzyyp.supabase.co/functions/v1/invoke-service
```

<Info>
Este único endpoint te permite invocar cualquier servicio disponible en SmartApe simplemente cambiando los identificadores de servicio y endpoint.
</Info>

## Autenticación

Todas las peticiones son controladas mediante **API Keys**. Asegúrate de incluir tu API key en cada solicitud para autenticar tu acceso.

<Warning>
Mantén tu API key segura y nunca la expongas en código del lado del cliente. Usa variables de entorno para almacenarla de forma segura.
</Warning>

## Parámetros requeridos

Cada petición a SmartApe debe incluir los siguientes parámetros obligatorios:

<ParamField body="api_key" type="string" required>
  Tu clave de API única para autenticación. Obtenla desde el [Dashboard de SmartApe](https://dashboard.smartape.com).
</ParamField>

<ParamField body="service_id" type="string" required>
  Identificador único del servicio que deseas utilizar (RAG, OCR, Video, etc.).
</ParamField>

<ParamField body="endpoint_id" type="string" required>
  Identificador del endpoint específico dentro del servicio seleccionado.
</ParamField>

<Note>
Los demás parámetros variarán dependiendo del servicio específico que estés invocando. Consulta la documentación de cada servicio para conocer sus parámetros adicionales.
</Note>

## Tipos de peticiones

SmartApe soporta dos tipos de peticiones según el contenido que necesites enviar:

<Tabs>
  <Tab title="Peticiones JSON">
    ### Peticiones con datos JSON
    
    Utiliza este formato cuando necesites enviar datos estructurados sin archivos.

    <CodeGroup>
    ```bash cURL
    curl -X POST "https://api.smartape.ai/v1/badec03b-494e-4219-a028-86fe4324b495" \
    -H "Content-Type: application/json" \
    -d '{
      "api_key": "sk_Gv1IQ88DgqUOlZApEivcaedXGCbB2epC",
      "service_id": "482111e2-6a27-42db-8420-43ade50759cc",
      "endpoint_id": "a50d8158-67e4-4ee7-b18f-6bcba0cc8068",
      "payload": {
        "atributo1": "value",
        "atributo2": "value"
      }
    }'
    ```

    ```javascript JavaScript
    const response = await fetch('https://api.smartape.ai/v1/badec03b-494e-4219-a028-86fe4324b495', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({
        api_key: 'sk_Gv1IQ88DgqUOlZApEivcaedXGCbB2epC',
        service_id: '482111e2-6a27-42db-8420-43ade50759cc',
        endpoint_id: 'a50d8158-67e4-4ee7-b18f-6bcba0cc8068',
        payload: {
          atributo1: 'value',
          atributo2: 'value'
        }
      })
    });

    const data = await response.json();
    ```

    ```python Python
    import requests
    import json

    url = "https://api.smartape.ai/v1/badec03b-494e-4219-a028-86fe4324b495"
    
    payload = {
        "api_key": "sk_Gv1IQ88DgqUOlZApEivcaedXGCbB2epC",
        "service_id": "482111e2-6a27-42db-8420-43ade50759cc",
        "endpoint_id": "a50d8158-67e4-4ee7-b18f-6bcba0cc8068",
        "payload": {
            "atributo1": "value",
            "atributo2": "value"
        }
    }

    response = requests.post(url, json=payload)
    data = response.json()
    ```
    </CodeGroup>

    <Check>
    Utiliza el formato JSON cuando trabajes con texto, consultas, configuraciones o cualquier dato estructurado que no requiera archivos.
    </Check>
  </Tab>

  <Tab title="Peticiones con archivos">

    ```bash cURL
    -F "endpoint_id=a50d8158-67e4-4ee7-b18f-6bcba0cc8068" \
    -F "atributo1=value" \
    -F "atributo2=value" \
    -F "file=@documento.pdf"
    ```


## Cómo cambiar entre servicios

La arquitectura unificada de SmartApe te permite cambiar entre diferentes servicios simplemente modificando los identificadores:

<Steps>
  <Step title="Mantén la estructura base">
    La estructura de tu petición permanece igual sin importar el servicio.
    
    <Info>
    No necesitas reescribir tu código de integración para cada servicio.
    </Info>
  </Step>

  <Step title="Cambia los identificadores">
    Simplemente actualiza `service_id` y `endpoint_id` según el servicio que necesites:
    
    ```javascript
    // Servicio RAG
    {
      service_id: "482111e2-6a27-42db-8420-43ade50759cc",
      endpoint_id: "a50d8158-67e4-4ee7-b18f-6bcba0cc8068"
    }

    // Servicio OCR
    {
      service_id: "OCR_SERVICE_ID",
      endpoint_id: "OCR_ENDPOINT_ID"
    }

    // Servicio Video
    {
      service_id: "VIDEO_SERVICE_ID",
      endpoint_id: "VIDEO_ENDPOINT_ID"
    }
    ```
  </Step>

  <Step title="Ajusta los parámetros específicos">
    Cada servicio puede requerir parámetros adicionales diferentes en el `payload`.
    
    <Tip>
    Consulta la documentación específica de cada servicio para conocer sus parámetros únicos.
    </Tip>
  </Step>
</Steps>

## Ventajas de la API unificada

<AccordionGroup>
  <Accordion title="Integración única y reutilizable">
    Escribe el código de integración una sola vez y reutilízalo para todos los servicios. Solo necesitas cambiar los identificadores según el servicio que necesites invocar.
  </Accordion>

  <Accordion title="Mantenimiento simplificado">
    Al tener una única API, cualquier actualización o mejora se refleja automáticamente en todos los servicios sin necesidad de modificar múltiples integraciones.
  </Accordion>

  <Accordion title="Curva de aprendizaje reducida">
    Una vez que aprendes a usar un servicio de SmartApe, ya sabes cómo usar todos los demás. La consistencia facilita la adopción y reduce errores.
  </Accordion>

  <Accordion title="Escalabilidad sin fricciones">
    Añade nuevos servicios a tu aplicación sin complejidad adicional. Si SmartApe lanza un nuevo servicio, puedes integrarlo inmediatamente con tu código existente.
  </Accordion>
</AccordionGroup>

## Ejemplo práctico

Imagina que necesitas usar tanto RAG como OCR en tu aplicación. Con SmartApe, usas el mismo código base:

```javascript
const callSmartApeService = async (serviceId, endpointId, payload) => {
  const response = await fetch('https://api.smartape.ai/v1/badec03b-494e-4219-a028-86fe4324b495', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      api_key: process.env.SMARTAPE_API_KEY,
      service_id: serviceId,
      endpoint_id: endpointId,
      payload: payload
    })
  });
  
  return await response.json();
};

// Llamada a servicio RAG
const ragResult = await callSmartApeService(
  'RAG_SERVICE_ID',
  'RAG_ENDPOINT_ID',
  { query: '¿Qué es SmartApe?' }
);

// Llamada a servicio OCR (misma función, diferentes IDs)
const ocrResult = await callSmartApeService(
  'OCR_SERVICE_ID',
  'OCR_ENDPOINT_ID',
  { document_url: 'https://example.com/document.pdf' }
);
```

<Tip>
Crea funciones auxiliares reutilizables como la del ejemplo para simplificar aún más tus llamadas a la API de SmartApe.
</Tip>
