## Requisitos previos

Antes de configurar Cursor para SmartApe, asegúrate de tener:

<AccordionGroup>
  <Accordion title="Cursor AI instalado">
    Descarga e instala [Cursor AI](https://cursor.sh) en tu sistema. Cursor es compatible con Windows, macOS y Linux.
  </Accordion>

  <Accordion title="API Key de SmartApe">
    Obtén tu API Key desde el [Dashboard de SmartApe](https://dashboard.smartape.com). Esta key es esencial para autenticar tus peticiones.
    
    <Warning>
    Nunca compartas tu API Key públicamente ni la incluyas directamente en tu código del lado del cliente.
    </Warning>
  </Accordion>

  <Accordion title="Conocimientos básicos de la API">
    Familiarízate con la [introducción de la API](/api-reference/introduction) para entender la arquitectura unificada de SmartApe.
  </Accordion>
</AccordionGroup>

## Configuración del proyecto

Sigue estos pasos para configurar Cursor en tu proyecto:

<Steps>
  <Step title="Crear directorio de configuración">
    En la raíz de tu proyecto, crea el directorio `.cursor` donde se almacenarán las reglas del proyecto:

    ```bash
    mkdir -p .cursor
    ```

    <Info>
    Este directorio contendrá las reglas personalizadas que Cursor AI utilizará para entender mejor tu proyecto y generar código optimizado para SmartApe.
    </Info>
  </Step>

  <Step title="Crear archivo de reglas">
    Crea el archivo `.cursor/rules.md` con el prompt personalizado para SmartApe que encontrarás en la siguiente sección.

    <Tip>
    Puedes copiar el prompt completo y pegarlo directamente en el archivo para ahorrar tiempo.
    </Tip>
  </Step>

  <Step title="Configurar variables de entorno">
    Crea un archivo `.env` en la raíz de tu proyecto para almacenar tu API Key de forma segura:

    ```bash .env
    SMARTAPE_API_KEY=sk_tu_api_key_aqui
    ```

    <Warning>
    Agrega `.env` a tu `.gitignore` para evitar exponer tus credenciales en el control de versiones.
    </Warning>
  </Step>

  <Step title="Verificar configuración">
    Reinicia Cursor o recarga la ventana del proyecto para que las nuevas reglas se apliquen correctamente.

    <Check>
    Ahora Cursor AI está listo para ayudarte con integraciones de SmartApe usando las mejores prácticas.
    </Check>
  </Step>
</Steps>

````markdown .cursor/rules.md
## Principios de código

### Estructura y organización

- Crea funciones reutilizables para las llamadas a SmartApe
- Separa la lógica de configuración de la lógica de negocio
- Implementa manejo de errores robusto en todas las peticiones
- Usa constantes para los IDs de servicios y endpoints
- Centraliza la configuración de la API (base URL, API key, etc.)

### Seguridad

- **NUNCA** incluyas API keys directamente en el código
- Usa variables de entorno para todas las credenciales
- Valida y sanitiza los datos de entrada antes de enviarlos
- Implementa rate limiting del lado del cliente cuando sea apropiado
- Registra errores sin exponer información sensible

### Manejo de peticiones

- Implementa retry logic con exponential backoff para errores temporales
- Usa timeouts apropiados para evitar requests colgados
- Valida respuestas antes de procesarlas
- Maneja correctamente archivos grandes con streaming cuando sea posible
- Implementa progress tracking para operaciones largas

Siempre que generes código TypeScript o JavaScript para SmartApe:

```typescript
// 1. Define tipos para los servicios
interface SmartApeConfig {
  apiKey: string;
  baseUrl: string;
}

interface ServiceRequest {
  serviceId: string;
  endpointId: string;
  payload?: Record<string, unknown>;
}

// 2. Crea una clase o funciones helper
class SmartApeClient {
  private config: SmartApeConfig;

  constructor(config: SmartApeConfig) {
    this.config = config;
  }

  async invokeService<T>(request: ServiceRequest): Promise<T> {
    try {
      const response = await fetch(this.config.baseUrl, {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json',
        },
        body: JSON.stringify({
          api_key: this.config.apiKey,
          service_id: request.serviceId,
          endpoint_id: request.endpointId,
          payload: request.payload,
        }),
      });

      if (!response.ok) {
        throw new Error(`SmartApe API error: ${response.statusText}`);
      }

      return await response.json();
    } catch (error) {
      console.error('Error calling SmartApe:', error);
      throw error;
    }
  }
}

// 3. Usa constantes para los IDs

### Código Python

Para proyectos Python, usa esta estructura:

```python
from typing import Dict, Any, Optional
import requests
import os
from dataclasses import dataclass

@dataclass
class SmartApeConfig:
    api_key: str
    base_url: str = "https://dfofxhxkdkwelswhzyyp.supabase.co/functions/v1/invoke-service"

class SmartApeClient:
    """Cliente para interactuar con la API de SmartApe"""
    
    # Constantes de servicios
    SERVICES = {
        'RAG': {
            'service_id': '9428c921-f57d-4a28-8dd8-14e30269cb1e',
            'endpoints': {
                'upload_file': '1dca4c67-8316-4c20-9e2a-2f7a6f7fddc5',
                'query': 'a50d8158-67e4-4ee7-b18f-6bcba0cc8068',
                'list_files': '6b6e6f3c-47ed-407e-b1af-82e15a6d3d9f',
                'delete_file': 'd4fc5d6e-d5a1-4f78-ae8f-38f7b3d3e6c2',
            }
        },
        'OCR': {
            'service_id': '482111e2-6a27-42db-8420-43ade50759cc',
            'endpoints': {
                'process_file': 'b3c388fb-11e6-42ab-af52-d385ab8c1efd',
                'get_status': 'a827a7d4-c5b7-4e91-90c8-7c2ed5f72f3e',
            }
        },
        'VIDEO': {
            'service_id': 'badec03b-494e-4219-a028-86fe4324b495',
            'endpoints': {
                'create_video': 'f90e729e-97cb-4b43-9b33-676956665589',
                'get_status': 'e92b3c8a-3d14-4e87-95f5-8f7a6c9b4d2e',
                'download_video': 'c7d4e9a1-6f82-4b3c-a4e5-9d8c7b6a5e4f',
            }
        }
    }
    
    def __init__(self, config: SmartApeConfig):
        self.config = config
        
    def invoke_service(
        self, 
        service_id: str, 
        endpoint_id: str, 
        payload: Optional[Dict[str, Any]] = None
    ) -> Dict[str, Any]:
        """Invoca un servicio de SmartApe"""
        try:
            data = {
                'api_key': self.config.api_key,
                'service_id': service_id,
                'endpoint_id': endpoint_id,
            }
            
            if payload:
                data['payload'] = payload
            
            response = requests.post(
                self.config.base_url,
                json=data,
                headers={'Content-Type': 'application/json'}
            )
            
            response.raise_for_status()
            return response.json()
            
        except requests.exceptions.RequestException as e:
            print(f"Error calling SmartApe API: {e}")
            raise

# Uso desde variables de entorno
def create_client() -> SmartApeClient:
    """Crea un cliente de SmartApe desde variables de entorno"""
    api_key = os.getenv('SMARTAPE_API_KEY')
    if not api_key:
        raise ValueError("SMARTAPE_API_KEY environment variable is required")
    
    config = SmartApeConfig(api_key=api_key)
    return SmartApeClient(config)
```

## Patrones comunes de uso

### Peticiones JSON (sin archivos)

Usa este patrón para servicios que solo requieren datos estructurados:

```typescript
// Ejemplo: Consulta RAG
const ragQuery = async (question: string) => {
  const client = new SmartApeClient({
    apiKey: process.env.SMARTAPE_API_KEY!,
    baseUrl: 'https://dfofxhxkdkwelswhzyyp.supabase.co/functions/v1/invoke-service',
  });

  return await client.invokeService({
    serviceId: SMARTAPE_SERVICES.RAG.serviceId,
    endpointId: SMARTAPE_SERVICES.RAG.endpoints.query,
    payload: {
      query: question,
      top_k: 5,
    },
  });
};
```

### Peticiones Multipart (con archivos)

Usa FormData para servicios que requieren archivos:

```typescript
const uploadFileToRAG = async (file: File, filePath: string) => {
  const formData = new FormData();
  formData.append('api_key', process.env.SMARTAPE_API_KEY!);
  formData.append('service_id', SMARTAPE_SERVICES.RAG.serviceId);
  formData.append('endpoint_id', SMARTAPE_SERVICES.RAG.endpoints.uploadFile);
  formData.append('file_path', filePath);
  formData.append('file_upload', file);

  const response = await fetch(
    'https://dfofxhxkdkwelswhzyyp.supabase.co/functions/v1/invoke-service',
    {
      method: 'POST',
      body: formData,
    }
  );

  if (!response.ok) {
    throw new Error(`Upload failed: ${response.statusText}`);
  }

  return await response.json();
};
```

## Mejores prácticas adicionales

### Manejo de errores

Implementa manejo de errores exhaustivo:

```typescript
interface SmartApeError {
  status: 'error';
  message: string;
  code?: string;
}

const handleSmartApeResponse = <T>(response: T | SmartApeError): T => {
  if ('status' in response && response.status === 'error') {
    throw new Error(response.message);
  }
  return response as T;
};
```

### Retry Logic

Para operaciones críticas, implementa reintentos:

```typescript
const retryWithBackoff = async <T>(
  fn: () => Promise<T>,
  maxRetries = 3,
  baseDelay = 1000
): Promise<T> => {
  for (let i = 0; i < maxRetries; i++) {
    try {
      return await fn();
    } catch (error) {
      if (i === maxRetries - 1) throw error;
      await new Promise(resolve => 
        setTimeout(resolve, baseDelay * Math.pow(2, i))
      );
    }
  }
  throw new Error('Max retries exceeded');
};
```

## Recordatorios importantes

1. **Seguridad primero**: Nunca expongas API keys en el código del cliente
2. **Variables de entorno**: Usa `.env` para todas las credenciales
3. **Manejo de errores**: Siempre implementa try-catch y validación
4. **Tipos fuertes**: En TypeScript, define interfaces para todas las respuestas
5. **Código reutilizable**: Crea helpers y utilidades para evitar duplicación
6. **Documentación**: Comenta código complejo y documenta funciones públicas
7. **Testing**: Implementa tests unitarios para las funciones de integración
8. **Logging**: Registra errores de forma útil sin exponer datos sensibles
````
