## Cómo funciona

SmartApe simplifica el proceso de integración de servicios de IA en tu aplicación:

<Steps>
  <Step title="Regístrate y obtén tu API Key">
    Crea tu cuenta en el dashboard de SmartApe y obtén tus credenciales de acceso.
    
    <Card title="Accede al Dashboard" icon="arrow-right" href="https://dashboard.smartape.com">
      Regístrate ahora y obtén tu API Key gratis
    </Card>
    
    <Check>
    Tu API Key te da acceso instantáneo a todos los servicios disponibles.
    </Check>
  </Step>

  <Step title="Elige el servicio que necesitas">
    Explora nuestro catálogo de servicios de IA y selecciona el que mejor se adapte a tus necesidades.
    
    <Tabs>
      <Tab title="RAG">
        **Retrieval Augmented Generation** - Sistemas de búsqueda y generación de contenido basados en documentos.
        
        - Chatbots inteligentes
        - Asistentes virtuales
        - Sistemas de Q&A empresariales
      </Tab>
      
      <Tab title="OCR">
        **Reconocimiento Óptico de Caracteres** - Extracción de texto e información de imágenes.
        
        - Digitalización de documentos
        - Procesamiento de formularios
        - Automatización documental
      </Tab>
      
      <Tab title="Video">
        **Procesamiento de Video** - Análisis y extracción de información de contenido audiovisual.
        
        - Análisis de contenido multimedia
        - Transcripción automática
        - Generación de resúmenes
      </Tab>
    </Tabs>
    
    <Tip>
    Puedes usar múltiples servicios en la misma aplicación sin configuraciones adicionales.
    </Tip>
  </Step>

  <Step title="Integra con una sola API">
    Realiza llamadas a nuestra API unificada con tu API Key y comienza a usar los servicios inmediatamente.
    
    <CodeGroup>
    ```bash cURL
    curl -X POST 'https://api.smartape.com/v1/service/invoke' \
      -H 'Authorization: Bearer YOUR_API_KEY' \
      -H 'Content-Type: application/json' \
      -d '{
        "service": "rag",
        "action": "query",
        "data": {
          "question": "¿Cuál es el horario de atención?",
          "collection": "my_documents"
        }
      }'
    ```

    ```javascript Node.js
    const response = await fetch('https://api.smartape.com/v1/service/invoke', {
      method: 'POST',
      headers: {
        'Authorization': `Bearer ${process.env.SMARTAPE_API_KEY}`,
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({
        service: 'rag',
        action: 'query',
        data: {
          question: '¿Cuál es el horario de atención?',
          collection: 'my_documents'
        }
      })
    });

    const result = await response.json();
    console.log(result);
    ```

    ```python Python
    import os
    import requests

    response = requests.post(
        'https://api.smartape.com/v1/service/invoke',
        headers={
            'Authorization': f'Bearer {os.getenv("SMARTAPE_API_KEY")}',
            'Content-Type': 'application/json'
        },
        json={
            'service': 'rag',
            'action': 'query',
            'data': {
                'question': '¿Cuál es el horario de atención?',
                'collection': 'my_documents'
            }
        }
    )

    result = response.json()
    print(result)
    ```

    ```php PHP
    <?php
    $apiKey = getenv('SMARTAPE_API_KEY');

    $ch = curl_init('https://api.smartape.com/v1/service/invoke');
    curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
    curl_setopt($ch, CURLOPT_POST, true);
    curl_setopt($ch, CURLOPT_HTTPHEADER, [
        'Authorization: Bearer ' . $apiKey,
        'Content-Type: application/json'
    ]);
    curl_setopt($ch, CURLOPT_POSTFIELDS, json_encode([
        'service' => 'rag',
        'action' => 'query',
        'data' => [
            'question' => '¿Cuál es el horario de atención?',
            'collection' => 'my_documents'
        ]
    ]));

    $response = curl_exec($ch);
    $result = json_decode($response, true);
    print_r($result);
    ?>
    ```
    </CodeGroup>

    <Warning>
    Nunca compartas tu API Key públicamente. Usa variables de entorno para almacenar tus credenciales de forma segura.
    </Warning>
  </Step>

  <Step title="Integra múltiples servicios fácilmente">
    Una de las mayores ventajas de SmartApe es que todos los servicios comparten la misma estructura de integración.
    
    <Info>
    Una vez que hayas integrado un servicio, agregar servicios adicionales es prácticamente instantáneo.
    </Info>
    
    <AccordionGroup>
      <Accordion title="Estructura de API unificada" icon="code">
        Todos los servicios utilizan el mismo endpoint y formato de solicitud. Solo cambia el parámetro `service` para acceder a funcionalidades completamente diferentes.
        
        ```javascript
        // Servicio RAG
        { service: 'rag', action: 'query', data: {...} }
        
        // Servicio OCR  
        { service: 'ocr', action: 'extract', data: {...} }
        
        // Servicio de Video
        { service: 'video', action: 'analyze', data: {...} }
        ```
      </Accordion>
      
      <Accordion title="Misma autenticación para todo" icon="key">
        Una sola API Key te da acceso a todos los servicios disponibles. No necesitas gestionar múltiples credenciales, tokens o métodos de autenticación diferentes.
      </Accordion>
      
      <Accordion title="Patrones de uso consistentes" icon="arrows-rotate">
        Los patrones de manejo de errores, paginación, filtrado y otras operaciones son idénticos entre servicios, lo que reduce drásticamente la curva de aprendizaje.
      </Accordion>

      <Accordion title="Ampliación sin refactorización" icon="puzzle-piece">
        Agregar nuevos servicios a tu aplicación no requiere refactorizar tu código existente. Simplemente reutiliza tu lógica de integración actual y cambia los parámetros según el servicio que necesites.
      </Accordion>
    </AccordionGroup>
    
    <Check>
    Aprende una vez, úsalo siempre. La consistencia en la integración te permite expandir las capacidades de IA de tu aplicación en minutos, no en semanas.
    </Check>
  </Step>
</Steps>
